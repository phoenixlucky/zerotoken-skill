# 搜索外部资料规范

> 触发：任务需要外部资料（新闻、人物、公司、社交平台内容、实时信息等）。

## 优先级

| 优先级 | 方式 | 条件 |
|--------|------|------|
| 🥇 本地浏览器 MCP 桥 | 通过真实浏览器搜索（搜索引擎不限百度，按效果选） | 本地存在 MCP 桥脚本且服务在线 |
| 🥈 宿主自带的抓取工具（如 `web_fetch`） | 备选，仅当浏览器桥不可用 | 无条件 |

> **为什么优先真实浏览器？** 纯 HTTP 抓取依赖搜索引擎结果页，曾被反爬返回完全无关内容；
> 真实浏览器搜索（Playwright/Chrome）结果精准可控。

## 先探测，不要硬编码路径

浏览器桥的调用入口**按实际安装位置探测**，不要假定某个 skill 名或目录存在。探测顺序：

```text
1. 宿主已注册的浏览器类 MCP 工具（如 mcp-server 提供的 search / navigate）
2. 仓库或用户目录下已有的 MCP 桥：.reasonix/skills/*/mcp_call.py、mcp-bridge.js
3. 都没有 → 回退到 web_fetch，或询问用户希望的检索方式
```

找到入口后，**Windows 上一律通过 Python 包装脚本调用**（`mcp_call.py` 等），
不要在 PowerShell 里直接调 `node mcp-bridge.js`：
PowerShell 的引号嵌套与 GBK 编码会破坏 JSON 参数（见 [`windows-powershell.md`](windows-powershell.md) 陷阱 5）。

## 真实浏览器能搜什么

| 场景 | 示例 | 形态 |
|------|------|------|
| 🔍 通用搜索 | 搜索新闻、人物、事件 | `<wrapper> search 关键词` |
| 🐦 社交媒体动态 | 搜微博、知乎、小红书上的内容 | `<wrapper> search 微博 关键词` |
| 🏢 公司/产品信息 | 查询公司背景、产品评测 | `<wrapper> search 公司名 评价` |
| 📰 最新资讯 | 今日热点、行业动态 | `<wrapper> search 今日 热点` |

> **无需为每个平台找专用 MCP server** — 真实浏览器通杀反爬严格的网站；搜索引擎按检索效果自由选择。

**若浏览器桥不可用**：允许使用当前网络可用的其他搜索方式（如 `web_fetch`），
不要因为首选方案不可用就放弃搜索。

## 什么情况走抓取工具

仅当以下条件**全部满足**时才回退：

1. 浏览器桥入口不存在或 MCP 服务离线
2. 目标网站没有反爬（非社交平台、非登录墙）
3. 仅需获取静态页面内容（非 SPA 页面）

## ❌ 禁用行为

- **禁止用抓取工具直抓社交媒体（微博/知乎/小红书等）** — 全部有登录墙/反爬，100% 失败
- **禁止自己写 Playwright/Puppeteer 脚本** — 已有现成的 MCP 桥，一行搞定
- **禁止用抓取工具直连搜索引擎（Google/百度/Bing）** — 纯 HTTP 请求会被机器人检测拦截
